# Component branding

- `arch-linux.svg` is the official scalable Arch Linux artwork from
  <https://archlinux.org/art/> and remains subject to the Arch Linux trademark
  policy.
- `hyprland.svg` is Hyprland's upstream `assets/header.svg`, distributed under
  the upstream BSD-3-Clause project license. Hyprland's name and logo remain
  trademarks of Hyprland Development.
- `quickshell.svg` is the icon shipped by the official Arch `quickshell`
  package and comes from the upstream Quickshell project.
- `voidline.svg` is the canonical Voidline v4 project mark supplied by the
  project author. The runtime copy removes editor metadata and the external
  SVG DTD but preserves the original geometry and colors.

These marks identify detected components in Settings. They are not used for
endorsement or promotional banners.
